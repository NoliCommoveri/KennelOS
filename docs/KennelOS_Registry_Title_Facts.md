# Dog-records fact check: FCI studbook codes, AKC imports, AKC title order

Compiled 2026-11-14. Every fact has a source URL and a short quote, or is marked **UNCONFIRMED**.

**How the sources were read:** The FCI table (1a) comes from the FCI PDF you uploaded, read with a PDF text tool. Each code was assigned to the studbook or appendix column by its position on the page. FCI's own links (`FCI-LDO-23747.pdf`, `22511.pdf`) were unreadable to my tools, and FCI's FAQ now points to `FCI-LDO-23800.pdf`. ### 1c. Ambiguous or retired codes

- **CKC:** Canadian Kennel Club vs Continental Kennel Club. Same letters, different registries.
  - AKC and UKC do not treat the Continental registry like the Canadian one. One local-news source says neither recognizes Continental registrations, but that source is not AKC's own. **UNCONFIRMED** from an AKC page.
- **KC:** the UK Kennel Club, and "KC" inside longer codes. Compare "KCC" (Chile), "KCP" (Peru), "KCU" (Uruguay).
- **PK:** Bulgaria's studbook per the list. Poland's code is "PKR", similar but different.
- **S / SE / AS (Sweden):** "S" is retired, "for dogs born and registered before 01/01/2010". AS is still used for nationally recognised breeds.
- **Retired or dated codes:**
  - Italy LOI/LIR (before 1 Nov 2010)
  - Poland PKR/KW (registered before 14 Feb 2019)
  - Israel appendix ISBR (until 31 Aug 2010, now ISAP)
  - Slovakia SHPK/SPKP (born before 2002 / after 2000, overlapping as printed)
  - Denmark DK (since 2007), Finland FI (since 2009), Norway NO (since 2009)
  - Czech ČLP (studbook, for dogs registered from 1 Oct 2024) and R ČLP (appendix)
  - Norway ANO (appendix since 18 Nov 2025)
  - AKC pedigrees: ANKC became Dogs Australia in 2022.

### Order rule

- **Prefix vs suffix:** "Most titles go at the end of a dog's registered name. The exceptions are championship titles." (https://www.akc.org/expert-advice/sports/dog-sport-titles/)
- **Multiple titles on one side:** **UNCONFIRMED.** The AKC title pages gave no ordering rule for multiple prefix or multiple suffix titles.
  - Forum posts (not AKC) claim an order of obedience, rally, tracking, hunt test, agility, then certificates like CGC last, and "order AKC recognized each event". Treat these as folklore, not a rule.
  - The AKC database order is best taken from a dog's AKC record page, which I did not access.
- **Repeat titles:** a number follows the abbreviation, e.g. "GCHP2, CM2, UDX2" (main title page), marked "#" in the lists.
